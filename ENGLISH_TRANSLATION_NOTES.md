# English translation

This package is an English-language version of IC-SDR (original: https://github.com/LuislopezMartinez/IC-SDR).

## What was translated

- README, DISTRIBUTION, VS Code tasks/launch names, and the Windows build script
- Desktop UI labels, buttons, menus, status text, maps, decoder panels, filter names, and scanner controls
- Startup, log, and decoder status messages
- Default memory names, groups, and frequency descriptions
- Tests that asserted Spanish strings

## Compatibility

Spanish values from the original app are still accepted when loading settings and memories:

- APRS views: `PAQUETES` → `PACKETS`, `ESTACIONES` → `STATIONS`, `MENSAJES` → `MESSAGES`
- Band name: `SONDAS` → `RADIOSONDES`
- Memory groups: `SIN GRUPO` → `UNGROUPED`, `TODAS` → `ALL`, `REPETIDORES` → `REPEATERS`, `APRS ESP` → `APRS SPAIN`, plus the default Barcelona group names
