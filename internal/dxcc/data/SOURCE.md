# Big CTY

This copy of `cty.dat` comes from the maintained Big CTY mirror at
https://github.com/jj1bdx/cty.dat and is embedded to keep DXCC lookup fully
offline. The external `DATA/tools/ft8/cty.dat` file, when present, overrides
this copy so operators can update the database without recompiling IC-SDR.

Copyright and redistribution permission are preserved in
`cty.dat.copyright.txt`.
